Designed a **serverless, event-driven data lake architecture** for centralised data ingestion and near-real-time analytics.

#### Architecture

```text

                              │
                              ▼
                     ┌─────────────────┐
                     │  Amazon Kinesis │
                     └────────┬────────┘
                              │

                     │ Event Processing │
                     └────────┬────────┘
                              │
                              ▼
                     ┌─────────────────┐
                     │   Amazon S3     │
                     │   DATA LAKE     │
                     └────────┬────────┘
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
             ┌────────────┐      ┌────────────┐
             │   Athena   │      │  DynamoDB  │
             └─────┬──────┘      └────────────┘
                   │
                   ▼
             ┌────────────┐
             │ QuickSight │
             └────────────┘
```

#### Key Technologies

* Fine-grained access control
* Self-service BI
